\# Power Grid Stability Prediction Using Machine Learning



\## Project Overview

This project uses Machine Learning algorithms to predict the stability of an electrical power grid based on simulated grid parameters.



The objective is to classify a power grid operating condition as \*\*Stable\*\* or \*\*Unstable\*\*.



\## Dataset

\- Dataset: UCI Electrical Grid Stability Simulated Data

\- Source: https://archive.ics.uci.edu/dataset/471/electrical+grid+stability+simulated+data

\- Features include response-time parameters, power-related parameters and price elasticity coefficients.



\## Machine Learning Algorithms

1\. Random Forest

2\. K-Nearest Neighbors (KNN)

3\. Support Vector Machine (SVM)

4\. Gaussian Naive Bayes



\## Tools and Technologies

\- Python

\- NumPy

\- Pandas

\- Matplotlib

\- Scikit-learn

\- Jupyter Notebook



\## Model Evaluation

The models are compared using:

\- Accuracy

\- Classification Report

\- Confusion Matrix



\## Important Note

The project uses simulated electrical grid data. Its predictions are not validated for direct real-world grid protection or control.
